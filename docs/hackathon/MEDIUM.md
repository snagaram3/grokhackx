# The phrase you already own is printing somewhere. Most tools invent why.

*HawkxAI is a footprint desk, not a trend list. Plug a name. Keep the receipts. Leave the story alone.*

---

Every morning a marketer has the same chore.

They shipped a name — a product, a hashtag, a line. Overnight it printed somewhere. To find it they babysit five feeds, paste screenshots into a slide, and then someone asks *why* it is trending.

If they do not have an answer, they invent one.

Brandwatch is a listening seat most teams will never get. A chatbot will write a cause with no tape behind it. By the time the deck is pretty, the footprint has already moved.

That is the friction. Not “what is loud on the internet.” A smaller, meaner question:

**Where did *our* phrase land — and what can we quote without making a story up?**

---

## What most platforms get wrong

Most trend platforms tell you what is trending.

They rank the world. They do not rank *your* campaign. They will not tell you that the same hashtag printed on two names, or that Reddit is arguing privacy while another feed is still selling the hype.

Imagine “AI Glasses.”

Hype on one platform. Privacy on Reddit. Barely a mention on Hacker News.

That gap is not a vibe. It is **platform divergence**, calculated in code. A single-platform spike is a bubble. Heat on more than one community is a different animal. The number is a ratio. The model is not allowed to narrate it.

> Receipts only. If the tape is thin, the map stays thin. We never invent a why.

## Plug a name you already own

[HawkxAI](https://hawkxai-qalms3xvxq-uc.a.run.app/footprint) is the live footprint desk for a campaign name you already own.

You plug it. An agent collects live receipts — where it printed, which hashtags and URLs rode along, when the first print hit. The same desk fills: a mind map, related prints, a brief a sales team can take into a room.

Related names connect on that map **only when they share a real artifact** — the same hashtag, the same URL, a QR-shaped code if one printed. No invented bridge. Empty stays empty.

The product is not a chatbot. It is a chore, handed off:

collect → score → store → put it on the desk.

## One tape. Three jobs.

The same receipts answer different questions. That is the whole product.

**Footprint** is where it printed. The hub is the name you plugged. Branches are prints that actually co-occurred. Click a receipt and you leave us for the source. That is the point.

**Lineage** rides under every receipt: which tool found it, and when. If a brief leaves the room, you can still audit the collect step. Memory you can trust — not a second product.

**Insights** is not a search ranking. It traces the name back — the origin page, the family it sits in, the oldest dated receipt we can prove. A taproot. If two senses collide, the desk forks. We do not mash the car and the person into one myth.

**Research** is the brief you would write if you had an hour. Wikipedia, the open web, Hacker News — each line is a citation, not a paragraph we dreamed up. Lineage stays on the source.

Footprint: where did it print.  
Insights: where did it start.  
Research: what can I cite.

Same tape. Different person asking.

## The agent does the heavy lifting

This piece was created for the purpose of entering the [All Things Agentic](https://allthingsagentichackathon.devpost.com/) hackathon — Taskmaster. Contest opened 4 August 2026. HawkxAI was created in the submission window.

Two services on Cloud Run. One job.

**Gemini 3.5 Flash** clusters related names and ranks titles that already exist.

**Google ADK** runs the ingest agent. It fans out, pulls live receipts, scores them, writes a snapshot. It does not invent posts. X is not the centerpiece.

When a receipt lands we stamp the tool and the time. Snapshots go to Cloud Storage. The live trend tape is never overwritten by the fleet. Honesty is the architecture.
